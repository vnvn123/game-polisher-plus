# Game Polisher Plus

I'm attaching two files. The first contains the current, unfinished version of my game. The second is my mega-prompt, which explains in detail what I want the ideal version of the game to look and function like.

Please use both files to improve my existing game until it matches the specification as closely as possible. Do not rebuild the game from scratch. Preserve the existing systems, working features, and overall design wherever possible.

You may suggest changes to anything you believe is seriously unbalanced or illogical, but do not make those changes without my permission.

Make sure every item, button, menu, and interface element fits the same visual style and feels like part of one cohesive game. Most importantly, preserve the existing art style and designs of the characters and weapons. You should still add more weapon illustrations and other missing artwork, but make sure all new assets match the existing style.

This project was built with [Lovable](https://lovable.dev).
